## Contributing

### PR Guidelines

1. Read the PR template at `.github/PULL_REQUEST_TEMPLATE.md`
2. Search for existing open/closed PRs before submitting
3. One problem per PR
4. Test on at least one harness and report results
5. Describe the problem you solved, not just what you changed
