# Initialize specai

Set up the required directory structure for specai in this repository.

## ABSOLUTE RULE

**Initialization MUST be done before any specai feature work starts. Verify the directory exists and config is valid before proceeding.**

## Initialization Steps

1. **Directory Structure:** Create the base directory in the project root if it does not exist:
   - `docs/specai/`
2. **Report:** Confirm to the user that the directory was created (or already existed).

> To configure models and agents, use `/specai-config`.
