# specai-verify — Verification

Verify the current implementation against the acceptance criteria in the spec and plan documents.

1. Find the relevant plan/spec files in `docs/specai/`.
2. Check each acceptance criterion against the implementation.
3. Report pass/fail for each criterion.
4. If there are failures, suggest corrective tasks.
