---
description: "Set senior philosophy intensity: off, lite, medium, or ultra."
---
Change the senior philosophy intensity level. Read ~/.config/specai/config.json, update seniorMode to the requested level (lite|medium|ultra|off). If no level specified, report current level.

Levels:
- off: No changes
- lite: Build what's asked, suggest lazier alternative
- medium: Full ladder enforced, minimalism active (default)
- ultra: YAGNI extremist, question the task itself
